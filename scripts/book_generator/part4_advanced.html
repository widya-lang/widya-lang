12.1 Green Threads & Task Worker: Model Konkurensi Ringan

Dalam arsitektur komputasi modern, pembuatan thread sistem operasi (OS native thread) memerlukan biaya alokasi memori yang cukup besar (umumnya 1–2 MB per tumpukan thread). Widya-Lang menerapkan model konkurensi Green Threads (M:N Task Scheduler) di mana ribuan tugas komputasi independen dijadwalkan secara kooperatif di atas sejumlah kecil thread fisik prosesor. Dengan jejak tumpukan awal hanya 4 KB, sistem dapat menjalankan 100.000 tugas konkuren secara simultan tanpa menghabiskan kapasitas RAM server.

┌────────────────────────────────────────────────────────┐ │ Tugas Konkuren Widya (Green Threads: T1, T2, ... Tn) │ └───────────────────────────┬────────────────────────────┘ ▼ ┌────────────────────────────────────────────────────────┐ │ Penjadwal Tugas Tingkat Pengguna (Work-Stealing) │ └───────────────────────────┬────────────────────────────┘ ▼ ┌────────────────────────────────────────────────────────┐ │ Thread Prosesor Fisik OS (Core 1, Core 2, Core 3...) │ └────────────────────────────────────────────────────────┘

12.2 Saluran Komunikasi (Channels) Antar-Tugas & Worker Pool

Pola Worker Pool adalah standar industri untuk membatasi konsumsi sumber daya saat memproses ribuan pekerjaan komputasi berat secara paralel: 

impor "./modul/konkurensi.wya";

fungsi jalankan_worker_pool(jumlah_pekerja, daftar_tugas) {
    misal kanal_tugas = buat_saluran(panjang(daftar_tugas));
    misal kanal_hasil = buat_saluran(panjang(daftar_tugas));

    // Meluncurkan N pekerja (Worker Green Threads)
    untuk id_pekerja dalam 1..jumlah_pekerja {
        jalankan_tugas(fungsi() {
            selama benar {
                misal tugas = terima_dari_saluran(kanal_tugas);
                jika tugas == nihil { henti; }
                cetak("[Pekerja-" + ke_teks(id_pekerja) + "] Memproses:", tugas.id);
                misal hasil = tugas.nilai * 2; // Komputasi
                kirim_ke_saluran(kanal_hasil, { "id": tugas.id, "hasil": hasil });
            }
        });
    }

    // Menerbitkan tugas ke dalam antrean
    untuk t dalam daftar_tugas {
        kirim_ke_saluran(kanal_tugas, t);
    }
    tutup_saluran(kanal_tugas);
}

Mengamankan rute mikroservis dengan memvalidasi tanda tangan JSON Web Token (JWT) secara ketat pada lapisan perantara:

fungsi middleware_jwt_auth(permintaan, respon, handler_berikutnya) {
    misal header_auth = permintaan.headers["Authorization"];
    jika header_auth == nihil atau bukan diawali_dengan(header_auth, "Bearer ") {
        respon.kirim_json(401, { "galat": "Akses Ditolak: Token Bearer Tidak Ditemukan!" });
        kembalikan;
    }

    misal token = potong_teks(header_auth, 7);
    coba {
        misal klaim = VerifikasiTokenJWT(token, "kunci_rahasia_otoritas_2026");
        permintaan.konteks_user = klaim;
        handler_berikutnya(permintaan, respon);
    } tangkap (err) {
        respon.kirim_json(403, { "galat": "Token Tidak Sah atau Telah Kedaluwarsa!" });
    }
}

13.1 Aljabar Linier: Perkalian Matriks Berkinerja Tinggi

Operasi perkalian matriks adalah fondasi utama lapisan jaringan saraf tiruan (deep learning neural networks). Berikut adalah implementasi algoritma perkalian matriks murni di Widya-Lang: 

fungsi perkalian_matriks(mat_a, mat_b) {
    misal baris_a = panjang(mat_a);
    misal kolom_a = panjang(mat_a[0]);
    misal kolom_b = panjang(mat_b[0]);

    misal hasil = [];
    untuk i dalam 0..(baris_a - 1) {
        misal baris_baru = [];
        untuk j dalam 0..(kolom_b - 1) {
            misal akumulasi = 0;
            untuk k dalam 0..(kolom_a - 1) {
                akumulasi = akumulasi + (mat_a[i][k] * mat_b[k][j]);
            }
            tambah(baris_baru, akumulasi);
        }
        tambah(hasil, baris_baru);
    }
    kembalikan hasil;
}

14.2 Siklus Agen AI Otonom Multi-Putaran (Multi-Turn ReAct Loop)

impor "./modul/http_klien.wya";
impor "./modul/widyabase.wya";

fungsi agen_cerdas_investigasi(pertanyaan_pengguna) {
    misal db = BukaWidyaBase("operasional.wdb");
    misal memori_percakapan = [
        { "role": "system", "content": "Anda adalah Analis Sistem Widya-Lang berdaulat. Anda dapat mengeksekusi kueri WidyaBase dengan format: [KUERI: sql_command]" }
    ];

    tambah(memori_percakapan, { "role": "user", "content": pertanyaan_pengguna });

    // Putaran 1: Minta AI Menganalisis Kebutuhan Data
    misal respon_ai = PanggilOllamaChat("widya-coder:latest", memori_percakapan);
    cetak("[AI PIKIRAN]:", respon_ai);

    // Deteksi Pemanggilan Alat (Tool Calling)
    jika mengandung_teks(respon_ai, "[KUERI:") {
        misal perintah_sql = ekstrak_antara(respon_ai, "[KUERI:", "]");
        cetak("[AKSI EKSEKUSI WIDYABASE]:", perintah_sql);
        
        misal data_tabel = db.kueri(perintah_sql);
        tambah(memori_percakapan, { "role": "assistant", "content": respon_ai });
        tambah(memori_percakapan, { "role": "user", "content": "HASIL DATA WIDYABASE:\n" + ke_json(data_tabel) });

        // Putaran 2: AI Menyusun Jawaban Akhir Berdasarkan Data Riil
        misal kesimpulan_akhir = PanggilOllamaChat("widya-coder:latest", memori_percakapan);
        cetak("[KESIMPULAN FINAL AGEN]:\n", kesimpulan_akhir);
        kembalikan kesimpulan_akhir;
    }

    kembalikan respon_ai;
}
