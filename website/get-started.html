1. Instalasi di Windows (x64)

Paket distribusi resmi Windows dikemas dalam format ZIP mandiri yang berisi biner eksekusi widya.exe, perkakas linter, dan berkas pustaka standar bawaan.

AUnduh dan Ekstrak Otomatis via PowerShell

Buka PowerShell (Run as Administrator jika ingin mendaftarkan ke PATH sistem):

powershell 
# Unduh arsip rilis biner resmi v0.1.0
iwr https://widya-lang.org/downloads/widya-v0.1.0-windows-x64.zip -OutFile widya.zip

# Ekstrak ke direktori tujuan
Expand-Archive widya.zip -DestinationPath C:\Widya

# Daftarkan ke PATH sesi ini
$env:Path += ";C:\Widya\bin"

# Uji verifikasi biner
widya --versi

BUnduh Manual

Anda juga dapat mengunduh langsung berkas biner ZIP dari tautan berikut:

📥 Unduh widya-v0.1.0-windows-x64.zip (18.17 MB)

2. Instalasi di Linux (x86_64 / ARM64)

Widya-Lang pada arsitektur Linux memanfaatkan Direct Syscalls bebas glibc. Anda dapat mengompilasi langsung dari repositori inti dengan perkakas Cargo:

bash 
# Klon repositori resmi
git clone https://github.com/widya-lang/widya-lang.git
cd widya-lang

# Kompilasi rilis optimal
cargo build --release

# Pasang ke direktori lokal
sudo cp target/release/widya /usr/local/bin/

# Verifikasi instalasi
widya --versi

3. Pasang Ekstensi Editor VS Code

Ekstensi resmi widya-lang menyediakan penyorotan sintaks cerdas, cuplikan kode (*snippets*), pencocokan tanda kurung, dan integrasi ikon berkas .wya.

Langkah Pemasangan Berkas .VSIX:

1. Unduh paket ekstensi resmi: Unduh widya-lang-0.1.0.vsix

2. Buka Visual Studio Code.

3. Tekan Ctrl + Shift + X untuk membuka panel Extensions.

4. Klik menu titik tiga (...) di pojok kanan atas panel Extensions, lalu pilih Install from VSIX...

5. Pilih berkas widya-lang-0.1.0.vsix yang telah diunduh. Selesai!

4. Menulis & Menjalankan Program Pertama

Buat berkas baru bernama salam.wya dan ketikkan kode berikut:

salam.wya 
// Program Salam Pertama
fungsi salam_nusantara(provinsi, pulau) {
    kembalikan "Salam hangat dari " + provinsi + ", Pulau " + pulau;
}

fungsi utama() {
    variabel pesan = salam_nusantara("D.I. Yogyakarta", "Jawa");
    cetak(pesan);
}

Jalankan program melalui terminal dengan perintah:

widya jalankan salam.wya
> widya jalankan salam.wya
Salam hangat dari D.I. Yogyakarta, Pulau Jawa
[Eksekusi Berhasil • Durasi: 0.84 ms]

5. Referensi Perintah CLI Widya

Perintah Deskripsi Singkat
widya jalankan <file.wya> Mengeksekusi berkas sumber secara langsung menggunakan Virtual Machine register cepat.
widya kompilasi <file.wya> Mengompilasi berkas sumber menjadi biner natif mandiri atau bytecode teroptimasi.
widya uji Menjalankan test-runner otomatis mendeteksi blok pengujian uji_... dalam proyek.
widya format <path> Memformat sintaks kode program sesuai standar panduan gaya bahasa resmi.
widya linter <path> Memeriksa keamanan AST, deteksi kebocoran memori, dan kepatuhan UU PDP No. 27/2022.
widya paket <perintah> Mengelola dependensi ekosistem WPM (instalasi, audit, vendor offline, publikasi).
widya office convert <in> -o <out> Konversi dokumen universal Markdown/DOCX ke format PDF ISO 32000-1 (%PDF-1.7).
