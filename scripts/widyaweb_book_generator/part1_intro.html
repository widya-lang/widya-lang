Kata Pengantar: Siapa Saja Bisa Membuat Website Berdaulat!

Selamat datang di dunia rekayasa web modern! Jika Anda memegang buku ini dengan perasaan was-was karena merasa belum pernah belajar ilmu komputer, belum memahami bahasa pemrograman, atau bingung dengan istilah-istilah teknis asing yang bertebaran di internet—tarik napas dalam-dalam dan tersenyumlah: Buku ini ditulis khusus untuk Anda.

Selama bertahun-tahun, membuat sebuah website terasa rumit karena para pengembang dipaksa menginstal puluhan aplikasi berbeda: harus mengunduh runtime bahasa (seperti Node.js atau Python), memasang web server terpisah (seperti Nginx atau Apache), menyetel server database yang memakan RAM besar (seperti MySQL atau PostgreSQL), lalu mengunduh ratusan megabyte pustaka pihak ketiga yang sering kali rentan disusupi peretas.

Widya-Lang dan WidyaWeb Framework diciptakan untuk mengakhiri kerumitan tersebut. Framework ini mengusung prinsip Kedaulatan Digital Penuh:

  • Satu Biner untuk Semuanya (*Zero External Dependencies*): Seluruh mesin web, router, pembuat tampilan, sistem keamanan, hingga basis datanya telah menyatu di dalam satu berkas tunggal widya.exe. Anda tidak perlu menginstal runtime tambahan apapun!
  • Bahasa yang Ramah Logika Nusantara: Perintah-perintah logika pemrograman dapat ditulis dalam Bahasa Indonesia yang wajar (seperti fungsi, misal, jika, kembalikan, untuk, coba-tangkap) maupun istilah internasional standar.
  • Keamanan Bawaan Tanpa Perlu Jadi Ahli Siber: Enam lapis tameng pelindung web standar industri perbankan sudah aktif sejak detik pertama proyek Anda dibuat.

Bab 1: Mengenal Dunia Web & Filosofi WidyaWeb

1.1 Apa Sebenarnya yang Terjadi Saat Kita Membuka Website?

Sebelum kita mulai menulis kode, mari pahami terlebih dahulu cara kerja website. Bayangkan Anda sedang pergi ke sebuah Restoran:

💡 Analogi Restoran: Klien, Pelayan, dan Dapur
  • Browser Anda (Google Chrome / Edge) adalah Pelanggan yang duduk di meja makan.
  • Alamat Website (misal: http://localhost:8080/menu) adalah Daftar Pesanan yang ingin Anda minta.
  • Jaringan Internet & Protokol HTTP adalah Pelayan yang mencatat pesanan Anda dan membawanya ke dapur.
  • Web Server (WidyaWeb) adalah Koki di Dapur. Koki ini membaca pesanan Anda, mengambil bahan-bahan dari lemari pendingin (Basis Data / Database), memasaknya menjadi hidangan yang lezat, lalu menyerahkannya kembali ke pelayan untuk disajikan di hadapan Anda (menjadi tampilan halaman web di layar monitor).

Ketika Anda membuat program menggunakan WidyaWeb, tugas Anda adalah menjadi Kepala Koki yang mengatur: jika pelanggan memesan halaman Beranda, hidangan apa yang harus disajikan? Jika pelanggan mengirim formulir pendaftaran, bagaimana cara menyimpannya ke lemari basis data? Semuanya dilakukan secara teratur, bersih, dan cepat.

┌────────────────┐ Permintaan (HTTP Request) ┌──────────────────┐ │ │ ──────────────────────────────────────────► │ │ │ Browser │ │ WidyaWeb Server │ │ (Chrome, Edge) │ ◄────────────────────────────────────────── │ (Dapur Utama) │ └────────────────┘ Jawaban (HTTP Response) └────────┬─────────┘ (Berupa Teks HTML / JSON) │ Ambil/Simpan ▼ ┌──────────────────┐ │ Basis Data (Data)│ │ (Lemari Arsip) │ └──────────────────┘

1.2 Mengapa Memilih WidyaWeb? (Zero-Dependency & Kedaulatan Digital)

Bagi seorang pemula, salah satu rintangan terbesar saat belajar pemrograman web adalah proses instalasi yang membingungkan (*environment setup hell*). Di framework konvensional, Anda sering diminta mengetikkan perintah-perintah misterius seperti: 

# Kerumitan lama yang TIDAK PERLU Anda lakukan di WidyaWeb:
npm install -g something
pip install virtualenv
composer require vendor/package
sudo apt-get install php-fpm mysql-server nginx ... (Bisa memakan waktu berjam-jam!)

Jika salah satu komponen versi library-nya bertabrakan (*version conflict*), program Anda akan langsung macet total dengan pesan galat merah yang sulit dimengerti.

WidyaWeb membuang semua kerumitan tersebut ke tempat sampah:

  1. Tanpa Instalasi Tambahan: Anda hanya membutuhkan satu file program bernama widya.exe di komputer Anda. Tidak perlu menginstal Node.js, tidak perlu menginstal Python, tidak perlu menginstal XAMPP.
  2. Sangat Hemat Memori: Saat berjalan, server WidyaWeb hanya memakai memori RAM sekitar 10 MB hingga 25 MB (bandingkan dengan framework lain yang sering menyedot 300 MB hingga 1 GB RAM laptop Anda). Laptop berspesifikasi sederhana pun dapat menjalankannya dengan sangat mulus.
  3. Kecepatan Eksekusi Sangat Tinggi: Karena mesin utamanya dibangun menggunakan Rust tingkat sistem, WidyaWeb mampu melayani ribuan pengunjung secara bersamaan dalam hitungan milidetik (*sub-millisecond latency*).

1.3 Mengenal Bahasa Pemrograman Widya-Lang

Widya-Lang adalah bahasa pemrograman resmi di balik WidyaWeb. Dirancang dengan sintaks dwibahasa yang anggun, bahasa ini sangat intuitif bagi penutur Bahasa Indonesia:

Kata Kunci Widya Padanan Internasional Artinya dalam Bahasa Manusia Sehari-hari
misal nama = "Budi"; let / var / const "Tolong siapkan kotak ingatan bernama nama, dan isi dengan tulisan Budi."
fungsi sapa() { ... } function / def "Tolong buatkan serangkaian instruksi kerja bernama sapa."
jika (umur >= 17) { ... } if "Periksa kondisi: jika umur orang ini sudah 17 tahun ke atas, lakukan hal ini."
kalau { ... } else "Jika syarat sebelumnya tidak terpenuhi, maka lakukan hal ini sebagai gantinya."
kembalikan nilai; return "Selesaikan pekerjaan ini dan serahkan hasilnya kembali kepada si pemanggil."
cetak("Halo!"); console.log / print "Tuliskan tulisan Halo! ke layar terminal agar bisa dibaca manusia."
impor "./modul.wya"; import / require "Ambil dan gunakan alat bantu yang ada di berkas lain."
coba { ... } tangkap (e) { ... } try ... catch "Coba jalankan perintah ini. Jika tiba-tiba terjadi galat/error, tangkap dan tangani dengan aman tanpa membuat program mati mendadak."

1.4 Menyiapkan Alat Tempur di Komputer Anda (3 Langkah Mudah)

Mari pastikan komputer Windows Anda sudah siap. Anda hanya perlu menyiapkan tiga hal:

  1. Aplikasi Editor Kode: Visual Studio Code (VS Code)
    Jika Anda belum memilikinya, unduh gratis dari code.visualstudio.com. VS Code adalah buku catatan digital tempat kita mengetik kode program dengan rapi.
  2. Kompiler / Biner Eksekutabel Widya
    Berkas widya.exe sudah tersedia di folder proyek Anda: c:\widya-lang\widya.exe. Biner inilah yang akan menjalankan kode yang Anda tulis.
  3. Ekstensi Resmi Widya-Lang di VS Code
    Ekstensi ini membuat teks kode Anda memiliki warna-warni yang indah (*syntax highlighting*) sehingga mudah dibaca mata dan membantu mencegah salah ketik.
    • Buka VS Code.
    • Tekan tombol keyboard Ctrl + Shift + X (untuk membuka menu Extensions).
    • Klik tombol titik tiga (`...`) di sudut kanan atas panel Extensions.
    • Pilih menu Install from VSIX....
    • Arahkan ke berkas lokal: c:\widya-lang\editors\vscode\widya-lang-1.0.0.vsix.
    • Selesai! Sekarang VS Code Anda sudah mengenali bahasa Widya-Lang sepenuhnya.

1.5 Uji Coba Pertama: Memastikan Biner Widya Berfungsi

Mari buka terminal untuk pertama kali dan periksa apakah mesin Widya Anda sudah siap menyapa Anda:

🎯 Praktikkan Langkah Ini Sekarang
  1. Tekan tombol keyboard Windows + R, ketik powershell, lalu tekan Enter (atau buka tab Terminal di dalam VS Code dengan menekan Ctrl + `).
  2. Ketik perintah berikut lalu tekan Enter: 
    & "c:\widya-lang\widya.exe" --versi
  3. Anda akan melihat respon ramah dari sistem: 
    Widya-Lang Compiler & Runtime v1.0.0 (Enterprise Sovereign Edition)
Jika Anda melihat teks di atas, selamat! Mesin pemrograman Anda telah aktif 100% dan siap digunakan untuk membuat aplikasi web apapun yang Anda impikan.

Bab 2: Menyiapkan Komputer & Scaffold Proyek Baru Sekali Klik

2.1 Skrip Ajaib Pembuat Proyek (widyaweb_init.ps1)

Di masa lalu, seorang programmer pemula harus membuat belasan folder satu per satu, menyalin file konfigurasi, menyusun skema database, dan mengetik berkas pengaturan secara manual. Jika ada satu nama folder yang salah ketik (misalnya mengetik routs alih-alih routes), program akan langsung rusak.

Di WidyaWeb, kami telah menciptakan Skrip Scaffold Otomatis Sekali Klik bernama widyaweb_init.ps1. Skrip ini bertindak seperti mandor bangunan pintar yang langsung mendirikan pondasi rumah proyek Anda dalam hitungan 1 detik!

🎯 Cara Membuat Proyek Web Baru Anda
Buka terminal PowerShell Anda, lalu ketik perintah berikut: 
cd c:\widya-lang
powershell -ExecutionPolicy Bypass -File .\scripts\widyaweb_init.ps1 -NamaProyek "AplikasiTokoSaya" -Port 8080

Seketika itu juga di layar terminal Anda akan muncul animasi teks berikut: 

=================================================================
[*] MENGINISIALISASI PROYEK WIDYAWEB BARU: AplikasiTokoSaya
=================================================================
Direktori Tujuan : c:\widya-lang\AplikasiTokoSaya
Port Server      : 8080
[OK] Struktur direktori berhasil dibuat.
[OK] Modul inti WidyaWeb berhasil disalin ke app/.
=================================================================
[OK] PROYEK AplikasiTokoSaya BERHASIL DIINISIALISASI!
=================================================================
Langkah selanjutnya:
  1. Buka folder proyek di VS Code:
     code c:\widya-lang\AplikasiTokoSaya
  2. Jalankan server (atau tekan Ctrl+Shift+B):
     cd c:\widya-lang\AplikasiTokoSaya; & 'c:\widya-lang\widya.exe' 'main.wya'
  3. Akses via peramban di http://127.0.0.1:8080
=================================================================

2.2 Membedah Peta Rumah Proyek (Apa Isi Tiap Folder?)

Buka folder baru AplikasiTokoSaya di VS Code. Anda akan melihat susunan file yang rapi. Jangan merasa kewalahan melihat banyaknya file! Mari kita analogikan susunan folder ini seperti ruangan-ruangan di sebuah toko:

AplikasiTokoSaya/ ├── 📄 main.wya ──► SAKLAR UTAMA (Tombol menyalakan seluruh sistem toko) ├── 📄 craft.wya ──► TONGKAT AJAIB (Alat bantu mengisi data & mengelola toko) ├── 📄 config.base.wya ──► BUKU CATATAN PENGATURAN (Nama toko, nomor port, dll.) │ ├── 📁 app/ ──► RUANG MESIN RAHASIA (Komponen inti pengaman, database, & server) ├── 📁 routes/ ──► PAPAN PETUNJUK ARAH (Mengatur rute alamat halaman web) ├── 📁 models/ ──► LEMBAR FORMAT DATA (Menentukan bentuk data barang, pembeli, dll.) ├── 📁 views/ ──► DEKORASI TOKO (Tampilan HTML yang dilihat mata pengunjung) ├── 📁 public/ ──► ETALASE TERBUKA (Gambar, foto produk, file CSS desain) ├── 📁 data/ ──► BRANKAS BESI (Tempat menyimpan file database toko yang aman) ├── 📁 logs/ ──► BUKU CATATAN CCTV (Merekam siapa saja yang masuk dan apa yang terjadi) └── 📁 .vscode/ ──► TOMBOL PINTAS EDITOR (Pengaturan khusus untuk VS Code Anda)

Dengan pembagian ruangan yang jelas ini, kode program Anda tidak akan pernah bercampur aduk menjadi "spaghetti code" yang ruwet. Anda selalu tahu persis di mana harus meletakkan kode baru:

  • Mau menambah alamat URL baru? Buka folder routes/.
  • Mau mengubah warna atau tata letak tombol halaman? Buka folder views/ atau public/.
  • Mau mengubah nomor port server atau nama website? Buka config.base.wya.

2.3 Memahami Berkas Pengaturan (config.base.wya)

Mari buka berkas config.base.wya di VS Code. Ini adalah pusat komando website Anda. Isinya menggunakan struktur kamus (*key-value pair*) yang sangat mudah dibaca: 

// config.base.wya - Pengaturan Dasar Aplikasi Anda
fungsi dapatkan_konfigurasi_dasar() {
    kembalikan {
        // 1. Nama Website yang Muncul di Judul Browser
        "nama_aplikasi": "Aplikasi Toko Saya",
        "versi": "1.0.0",

        // 2. Pengaturan Alamat Jaringan Komputer
        "server": {
            "host": "127.0.0.1",  // Alamat lokal laptop Anda (localhost)
            "port": 8080,          // Pintu gerbang port aplikasi
            "batas_muatan_mb": 10  // Batas maksimal ukuran unggah berkas (10 MB)
        },

        // 3. Pengaturan Basis Data Penyimpanan Data
        "database": {
            "driver": "sqlite",
            "path": "./data/aplikasi.db"  // Lokasi berkas tempat data disimpan
        },

        // 4. Pengaturan Keamanan & Sesi Pengguna
        "keamanan": {
            "durasi_sesi_detik": 7200 // 7200 detik = sesi login aktif selama 2 jam
        }
    };
}
💡 Apa itu Nomor Port (seperti 8080)?
Bayangkan komputer Anda adalah sebuah hotel berbintang. Alamat IP (seperti 127.0.0.1) adalah alamat gedung hotelnya. Sedangkan Port (seperti 8080) adalah Nomor Kamar di dalam hotel tersebut. Jika Anda menjalankan server di port 8080, browser Anda harus berkunjung ke kamar nomor 8080 untuk menemui website Anda.
