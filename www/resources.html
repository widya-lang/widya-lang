Sumber Daya Widya-Lang

Temukan lembar contekan sintaks, panduan buku komprehensif, aset media kit resmi, dan verifikasi tanda tangan rilis.

📑 Lembar Contekan Sintaks (Syntax Cheatsheet)

Variabel & Tipe Data

// Deklarasi variabel misal nama = "Widya"; // Teks (String) misal versi = 1.0; // Float (Angka) misal port = 8080; // Int (Angka) misal aktif = benar; // Boolean (benar/salah) // Imutabel / Konstan konstan MAX_CONN = 1000;

Struktur Kontrol & Perulangan

// Percabangan kondisi jika (aktif && port > 1024) { cetak("Port aman"); } selain { cetak("Mode root"); } // Perulangan koleksi untuk (misal item di [1, 2, 3]) { cetak("Angka: " + ke_teks(item)); }

Fungsi & Generics

// Fungsi dengan inferensi tipe fungsi tambah(a: T, b: T) -> T { kembalikan a + b; } // Fungsi ekspresif bawaan misal salam = fungsi(nama) { kembalikan "Halo " + nama; };

Pattern Matching & ADT

pilihan Hasil { Ok(T), Err(E) } cocokkan respon { Hasil::Ok(data) => cetak(data), Hasil::Err(pesan) => cetak("Galat: " + pesan) }

Pustaka I/O & Sistem

// Pembacaan dan penulisan berkas misal isi = baca_berkas("data.txt"); tulis_berkas("output.txt", isi); // Lingkungan & Waktu misal env = baca_env("WIDYA_ENV"); misal epoch = waktu_sekarang_ms();

Kriptografi & Hash

// Hash SHA-256 & HMAC misal hash = sha256("teks_rahasia"); misal ttd = hmac_sha256("pesan", "kunci"); // Deteksi file & hapus jika (berkas_ada("kunci.pem")) { cetak("Kunci ditemukan"); }

🗄️ WidyaBase (Biner Mandiri & SQL Dwibahasa)

// CLI Standalone WidyaBase.exe WidyaBase.exe mulai --port 5432 --data pos.wdb WidyaBase.exe kueri "PILIH * DARI menu;" --data pos.wdb // Sintaksis SQL Bahasa Indonesia (Nusantara) BUAT_TABEL menu (id INT KUNCI_UTAMA, nama TEKS, harga ANGKA); SISIP_KE menu (id, nama, harga) NILAI (1, 'Kopi Susu', 18000); PILIH nama, harga DARI menu DIMANA harga >= 15000;
