Prinsip Rekayasa & Keunggulan Inti

Enam pilar fundamental yang membedakan Widya-Lang dari bahasa pemrograman konvensional.

🧠

Inferensi Tipe Hindley-Milner

Ketik kode secara ringkas dan alami layaknya bahasa dinamis tanpa anotasi tipe berlebih, namun nikmati 100% kepastian keamanan tipe saat waktu-kompilasi.

⚙️

Full Self-Hosting Compiler

Kompilator Widya ditulis dalam bahasa Widya itu sendiri. Terverifikasi deterministik penuh melalui tahapan Stage-0 → Stage-1 → Stage-2 tanpa deviasi biner.

🛡️

Pilar Kemandirian (Bebas Libc)

Berkomunikasi langsung dengan kernel Linux (x86_64/ARM64) melalui Direct Raw Syscalls tanpa ketergantungan runtime glibc atau pustaka pihak ketiga.

🔒

Kriptografi Pasca-Kuantum (PQC)

Kesiapan era komputasi kuantum dengan algoritma standar NIST FIPS 203 (ML-KEM Kyber) dan FIPS 204 (ML-DSA Dilithium) yang terpasang secara native.

📦

Manajer Paket WPM Berdaulat

Penyelesai pohon dependensi matematis berbasis PubGrub, verifikasi integritas Ed25519, serta mode zero-trust offline vendoring untuk keamanan rantai pasok.

🌐

Ekosistem Terpadu Berdaulat

Mendukung kerangka kerja rekayasa aplikasi tingkat industri: WidyaBase (basis data ACID), WidyaWeb (HTTP/3 SSR), WidyaDesktop, dan WidyaMobile.

Sintaks Alami, Logika Presisi

Eksplorasi kode program Widya-Lang dalam sintaks dwi-bahasa Nusantara yang intuitif dan ekspresif.

01. Halo Dunia & Inferensi Tipe

Deklarasi variabel otomatis dan fungsi modular.

02. ADT & Exhaustive Pattern Matching

Pencocokan pola struktural aman tanpa bahaya null-pointer.

03. Utas Paralel & Saluran Komunikasi

Model Aktor konkuren bebas data-race pada tingkat kernel OS.

04. Kriptografi Pasca-Kuantum (PQC)

Enkapsulasi kunci ML-KEM Kyber-768 tahan serangan kuantum.

program.wya 
// Program Perdana: Halo Dunia & Inferensi Tipe
fungsi sapa(nama) {
    kembalikan "Selamat datang di Widya-Lang, " + nama + "!";
}

fungsi utama() {
    variabel bahasa = "Widya";
    variabel versi = "0.1.0";
    
    cetak(sapa(bahasa));
    cetak("Versi Sistem: " + versi);
}
