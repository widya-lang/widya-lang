📜 Validasi Prestasi Digital

Verifikasi Keaslian E-Piagam & Sertifikat Juara

Lindungi atlet dari pemalsuan sertifikat untuk PPDB atau beasiswa. Seluruh sertifikat diterbitkan dengan tanda tangan digital HMAC-SHA256 yang lolos kurasi SIMT Puspresnas Kemendikdasmen.

Masukkan Nomor SK / Registrasi Piagam

Contoh nomor sertifikat resmi: IPSI/KEJURNAS/2026/XI/0842-EMAS

⚡ Standar Olimpiade

Inovasi Teknologi Terdepan Pencak Silat

Dirancang khusus untuk memenuhi standar kejuaraan berdaulat dari tingkat perguruan lokal hingga kejuaraan multievent dunia.

⚡

Konsensus 5 Juri Sub-15ms

Poin pukulan (+1) dan tendangan (+2) disahkan secara otomatis jika minimal 3 dari 5 juri menekan tombol dalam toleransi waktu 1.5 detik. Dilengkapi sintesis suara Gong tradisional dan Peluit frekuensi tinggi Web Audio API tanpa dependensi file eksternal.

📹

Video Assistant Referee (VAR)

Modul slow-motion replay instan 0.25x dan 0.5x langsung di meja Ketua Pertandingan. Dilengkapi kuota 2 kartu protes sudut merah dan biru sesuai regulasi resmi PERSILAT 2026.

⚖️

Timbangan Bluetooth BLE

Koneksi nirkabel langsung ke timbangan digital melalui Web Bluetooth API (standar W3C). Berat badan aktual atlet terbaca ke database dalam 5 detik, bebas kecurangan dan salah ketik.

📜

E-Sertifikat Anti-Fraud Puspresnas

Penerbitan piagam vektor resolusi tinggi dengan stempel QR Code dan enkripsi kriptografi HMAC-SHA256 yang terintegrasi untuk kurasi SIMT Puspresnas Kemendikdasmen.

📺

Mode Siaran OBS Broadcast MCR

Satu-klik mengubah latar belakang menjadi transparan (Alpha / Chroma Key) untuk menghasilkan *scorebug* dan *lower-third* yang siap dimasukkan ke OBS Studio, vMix, atau siaran YouTube Live.

🛡️

Kepatuhan UU PDP & Isolasi Tenant

Penerapan Row-Level Security (RLS) PostgreSQL memastikan data satu EO tidak bocor ke EO lain. Dokumen NIK, KK, dan rekam medis atlet terlindungi sesuai UU Perlindungan Data Pribadi No. 27/2022.
