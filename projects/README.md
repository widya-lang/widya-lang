# Direktori Proyek (Projects)

Direktori ini digunakan sebagai tempat penyimpanan proyek-proyek unggulan yang dikembangkan menggunakan ekosistem Widya-Lang.

## Daftar Proyek Aktif

1. **[widya_os](file:///home/devops/widya-lang/projects/widya_os/README.md)**: Sistem Operasi Desktop Berdaulat Generasi Baru dengan Shell Polimorfik Dinamis (Pilihan Tampilan Windows, macOS, atau Ubuntu 1-klik), Suite Aplikasi Produktivitas Bawaan (WidyaOffice), Booting < 2 Detik, dan Kriptografi Pasca-Kuantum (PQC).
2. **[widya_office_desktop](file:///home/devops/widya-lang/projects/widya_office_desktop/README.md)**: Suite Perkantoran Berdaulat Generasi Baru untuk Desktop (WidyaWriter, WidyaCalc, WidyaImpress, WidyaPDF) dengan dukungan native OMML Math Equations, Bulk Mail Merge, dan Tanda Tangan Digital PQC.
3. **[enterprise_microservice](file:///home/devops/widya-lang/projects/enterprise_microservice/Widya.toml)**: Blueprint microservice tingkat industri dengan actor supervision, pooling database berkinerja tinggi, metrik Prometheus, tracing Otel, dan autentikasi Post-Quantum.
4. **[arenasilat.id](file:///home/devops/widya-lang/projects/arenasilat.id/README.md)**: Platform pertandingan dan kejuaraan pencak silat nasional berbasis stack berdaulat Widya.

## Cara Membuat Proyek Baru
Untuk membuat proyek baru dengan Widya CLI:
```bash
cd projects
widya baru nama_proyek
```
