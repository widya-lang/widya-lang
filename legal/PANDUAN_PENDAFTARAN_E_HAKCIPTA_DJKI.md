## 2. LAMPIRAN CONTOH KODE SUMBER (SOURCE CODE SAMPLE - MAX 50 HALAMAN)
Untuk memenuhi syarat pendaftaran DJKI, sertakan potongan kode sumber berikut:
1. **Inti Lexer & Parser (`src/lexer.rs`, `src/parser.rs`)**:
   - Menunjukkan implementasi kata kunci natural Indonesia (`misal`, `biar`, `diketahui`, `diket`, `tetap`, `fungsi`, `jika`, `ulangi`).
2. **Kompilator Self-Hosted & LLVM Backend (`src/compiler.rs`, `src/llvm.rs`)**:
   - Menunjukkan mekanisme translasi kode sumber ke biner native.
3. **Mesin Multi-Agent & Blackboard (`src/ai.rs`, `src/runtime.rs`)**:
   - Menunjukkan arsitektur koordinasi otonom antar-agen cerdas.
4. **Mesin Basis Data Mandiri (`src/widyabase/mod.rs`)**:
   - Menunjukkan implementasi query engine SQL dwibahasa dan storage page engine.
