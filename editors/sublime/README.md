# Dukungan Resmi Widya-Lang untuk Sublime Text (3 & 4)

Paket sintaksis resmi untuk **Sublime Text** dengan penyorotan sintaksis `.sublime-syntax` modern dan pintasan komentar (`Ctrl+/`).

---

## 🚀 Cara Pemasangan

1. Buka Sublime Text.
2. Buka menu **Preferences** -> **Browse Packages...**.
3. Buat folder baru bernama `Widya`.
4. Salin seluruh isi direktori `editors/sublime/` ke dalam folder `Packages/Widya/`:
   ```bash
   cp -r editors/sublime/* ~/.config/sublime-text/Packages/Widya/
   ```
5. Berkas `.wya`, `.widya`, dan `.wd` akan otomatis disorot dengan skema warna aktif Anda.
