# Modul Presentasi Kuliah & Workshop PPTX Widya-Lang

Direktori ini memuat arsip presentasi slide formal berformat **Microsoft PowerPoint (.pptx)** rasio layar lebar **16:9** (*widescreen*) untuk kurikulum inti bahasa **Widya-Lang**.

Setiap bab dirancang secara profesional dengan palet warna khas, tata letak modern berstandar industri, ringkasan arsitektur sistem, terminal cuplikan kode program native, matriks perbandingan performa, serta bank evaluasi mandiri interaktif.

---

## Ringkasan Eksekutif Kurikulum Inti

- **Total Modul Inti**: 2 Seri Buku Inti Bahasa (Level Dasar & Level Lanjut)
- **Total Berkas PPTX Inti**: 80 Modul Slide Mandiri (40 Bab per Seri)
- **Total Slide Tayang**: 1.010 Slide Presentasi Lengkap
- **Standar Rasio**: 16:9 Widescreen (13.333" x 7.5")
- **Kompatibilitas**: Microsoft PowerPoint 2016+, Office 365, Google Slides, Apple Keynote, dan LibreOffice Impress

> **Catatan Ekosistem Lanjutan (Lokal / Ekstensi):**  
> Modul slide ekosistem lanjutan (WidyaBase, WidyaWeb, WidyaDesktop, WidyaMobile) disimpan secara lokal di lingkungan kerja pengembang atau melalui repositori paket terpisah agar repositori bahasa inti ini tetap ringan dan fokus.
