Mulai Membangun dengan Widya-Lang

Ikuti panduan langkah demi langkah ini untuk memasang perkakas, menyiapkan lingkungan pengembangan, dan merilis aplikasi pertama Anda.

1

Pemasangan Biner Mandiri

Pilih sistem operasi Anda untuk menjalankan pemasangan otomatis biner kompiler Widya-Lang:

Windows (PowerShell)
Linux / macOS (Bash)
Kloning Git & Kompilasi
Terminal Perintah
iwr https://get.widya-lang.org/ps1 -useb | iex
Verifikasi Pemasangan: Buka terminal baru dan ketik widya --version. Jika terpasang dengan benar, terminal akan mencetak widya 1.0.0-beta.1.
2

Siapkan Ekstensi Visual Studio Code

Dapatkan pengalaman pengembang terbaik dengan menginstal paket resmi `widya-lang-1.0.0.vsix` yang menyediakan penyorotan sintaks dwibahasa, integrasi Language Server Protocol (LSP), dan pelacak kesalahan cerdas.

Terminal VS Code CLI
code --install-extension dist/releases/v1.0.0/widya-lang-1.0.0.vsix

Atau unduh berkas biner ekstensi langsung: widya-lang-1.0.0.vsix lalu pasang via menu Extensions > Install from VSIX... di VS Code.

3

Buat Proyek Baru Anda

Gunakan antarmuka baris perintah (CLI) untuk membentuk struktur proyek standar:

Terminal Inisialisasi
# Untuk proyek umum / CLI widya baru HaloNusantara # Atau untuk proyek Desktop POS Kasir widya desktop inisialisasi PosKasir # Atau untuk proyek Seluler 10 Pilar (Android / iOS / PWA) widya mobile inisialisasi TokoMobile

Setiap proyek secara otomatis dilengkapi dengan berkas konfigurasi manifest widya.json dan direktori src/main.wya.

4

Menulis Program Pertama (`src/main.wya`)

Buka src/main.wya dan tuliskan kode logika dengan inferensi tipe otomatis:

src/main.wya
fungsi utama() { cetak("==========================================="); cetak("⚡ Halo Nusantara dari Widya-Lang v1.0.0!"); cetak("==========================================="); // Inferensi tipe Hindley-Milner otomatis misal daftar_fitur = ["Tipe Aman", "Web Framework", "Desktop Native", "Mobile 10 Pilar"]; untuk (misal item di daftar_fitur) { cetak("✓ Fitur Aktif: " + item); } }
5

Jalankan & Kompilasi Rilis Mandiri

Jalankan program secara instan dalam mode pengembangan, atau kompilasi ke biner mandiri produksi tanpa ketergantungan luar:

Terminal Eksekusi
# 1. Jalankan langsung dengan JIT / Interpreter widya jalan src/main.wya # 2. Audit Kualitas & Keamanan (Enterprise Grade A+) widya audit src/main.wya # 3. Kompilasi ke Biner Mandiri Siap Produksi widya bangun src/main.wya --target release -o bin/aplikasi_saya
Biner Mandiri: Berkas hasil kompilasi bin/aplikasi_saya dapat langsung dijalankan di server atau komputer pengguna tanpa perlu memasang runtime Rust, Node.js, atau Python!
6

Basis Data Mandiri Skala Industri (WidyaBase.exe)

Untuk penyimpanan data transaksional skala industri, jalankan mesin basis data mandiri WidyaBase.exe dengan SQL dwibahasa (Nusantara & ANSI) dan server PostgreSQL Wire Protocol v3.0:

Terminal WidyaBase
# 1. Jalankan daemon server PostgreSQL Wire Protocol (Port 5432) WidyaBase.exe mulai --port 5432 --data app.wdb # 2. Buka shell interaktif SQL dwibahasa (REPL) WidyaBase.exe sql --data app.wdb # 3. Kueri cepat dari terminal (Bahasa Indonesia atau ANSI) WidyaBase.exe kueri "PILIH * DARI pengguna DIMANA aktif = benar;" --data app.wdb --format json
Konektivitas Global: WidyaBase.exe mendengarkan pada port 5432 sehingga dapat langsung dihubungkan dari psql, DBeaver, TablePlus, Prisma, maupun klien bahasa pemrograman lainnya.
7

Manajemen Paket & Audit Keamanan Rantai Pasok (WPM)

Kelola dependensi proyek, audit keamanan rantai pasok (CVE/WSA), dan pasang pustaka resmi berdaulat bawaan:

Terminal WPM
# 1. Tambahkan pustaka resmi berdaulat (contoh: WidyaOffice atau WidyaBase) widya wpm add widya-office --versi 2.5.0 # 2. Audit keamanan rantai pasok & validasi Ed25519 widya wpm audit # 3. Periksa apakah dependensi memiliki versi pembaruan terbaru widya wpm outdated # 4. Cari pustaka di katalog registry widya wpm search "crypto"
Keamanan Kriptografis: WPM memvalidasi tanda tangan kurva Edwards Ed25519 dan hash SHA-256 pada setiap rilis pustaka untuk mencegah serangan supply-chain.
8

5 Pilar Kemandirian dari Pustaka Luar (Zero-Dependency Stack)

Gunakan modul murni bawaan untuk komputasi berdaulat tanpa bergantung pada crates eksternal, libc malloc, atau compiler C asing:

Terminal Kedaulatan
# Jalankan demonstrasi resmi 5 Pilar Kemandirian widya contoh/220_lima_pilar_kemandirian_pustaka_luar.wya # Uji integrasi seluruh suite pengujian kedaulatan cargo test --test pilar_kemandirian_test
Buku Putih Kedaulatan: Unduh DOKUMENTASI_PILAR_KEMANDIRIAN.pdf untuk spesifikasi teknis lengkap FIPS 180-4, RFC 8032, RFC 8439, Direct Syscall, dan MicroVM Unikernel.
