M Kata Pengantar & Manifest Kedaulatan Digital

Perkembangan teknologi komputasi selama lebih dari setengah abad telah membuktikan satu hukum sejarah yang tak terbantahkan: "Bangsa yang hanya menjadi konsumen bahasa pemrograman dan mesin basis data asing akan selalu berada di bawah subordinasi teknologi bangsa lain." Di era kecerdasan buatan, komputasi awan, dan persaingan geopolitik siber modern, kepemilikan atas fondasi bahasa komputasi dan mesin pengolah data adalah pilar terdepan dari kedaulatan digital nasional. Ketergantungan struktural pada lisensi asing, rantai pasok tertutup, dan infrastruktur komputasi eksternal menyimpan kerentanan strategis yang nyata bagi masa depan Republik Indonesia.

Widya-Lang dilahirkan bukan sekadar sebagai penerjemah kata kunci (wrapper atau transpiler sederhana). Widya-Lang adalah bahasa pemrograman mandiri dengan kompiler, interpreter, mesin inferensi tipe data, sistem modularitas, dan ekosistem basis data asli yang dibangun secara murni di atas arsitektur komputasi Rust modern. Dengan performa tinggi, jejak memori yang sangat efisien, dan sintaksis bercita rasa Nusantara, Widya-Lang menyajikan alternatif berdaulat yang tangguh untuk ekosistem perangkat lunak Indonesia.

Filosofi Tiga Pilar Utama Widya-Lang

  1. Kedaulatan Bahasa Nusantara (Sovereign Ergonomics): Memungkinkan anak bangsa berpikir, merancang, dan memprogram menggunakan idiom logis bahasa ibu mereka sendiri. Kata kunci seperti misal, tetap, fungsi, jika, untuk, selama, struktur, sifat, dan coba-tangkap menjadikan alur program sangat intuitif dan mudah dipelajari oleh jutaan pemula tanpa kehilangan daya ekspresif sistem perbankan skala enterprise.
  2. Ketahanan Sistem & Kinerja Skala Industri (Industrial Reliability): Widya-Lang menerapkan penanganan memori aman, penanganan galat deterministik, dan ekosistem tipe data kuat. Kode yang ditulis dalam Widya-Lang siap dijalankan untuk sistem perbankan berisiko tinggi, sistem avionik, perangkat IoT industri, maupun aplikasi kasir UMKM tanpa takut mengalami null pointer crash yang merugikan.
  3. Ekosistem Lengkap dalam Satu Genggaman (Batteries Included): Widya-Lang tidak membutuhkan pemasangan puluhan pustaka eksternal yang rapuh untuk memulai. Di dalam bundel rilis resminya telah terpasang mesin basis data WidyaBase, framework aplikasi desktop GUI (modul/desktop.wya), framework mobile (modul/mobile.wya), sistem kriptografi (AES-256, Ed25519, Post-Quantum Kyber), dan integrasi model AI lokal (widya-coder:latest).

1 Menyiapkan Lingkungan Pengembangan

1.1 Mengunduh & Memasang Kompiler Widya-Lang

Kompiler Widya-Lang didistribusikan dalam bentuk biner mandiri (standalone executable) yang tidak memerlukan pemasangan runtime pihak ketiga seperti Node.js, Python interpreter, atau Java Virtual Machine. Seluruh modul inti, mesin basis data tersemat (WidyaBase), dan modul grafis telah dipaketkan secara statis (statically linked) menggunakan Rust compiler, menghasilkan performa booting instan tanpa dependensi dinamis yang rapuh.

Platform Sistem Operasi Berkas Rilis Biner Langkah Instalasi & Pengaturan Variabel PATH
Windows x64 (10/11/Server) widya-v1.0.0-windows-x64.zip Ekstrak arsip zip ke direktori C:\widya-lang. Buka System Properties > Environment Variables, lalu tambahkan C:\widya-lang ke dalam variabel Path pengguna atau sistem.
Linux x86_64 / arm64 widya-v1.0.0-linux.tar.gz Jalankan perintah: tar -xvf widya.tar.gz && sudo mv widya /usr/local/bin/ kemudian pastikan izin eksekusi aktif via chmod +x /usr/local/bin/widya.
macOS (Apple Silicon & Intel) widya-v1.0.0-darwin.tar.gz Jalankan: tar -xvf widya.tar.gz && sudo cp widya /usr/local/bin/. Izinkan akses biner melalui System Settings > Privacy & Security jika diminta.

Setelah konfigurasi variabel lingkungan selesai, buka terminal PowerShell atau Bash baru dan verifikasi ketersediaan kompiler dengan menjalankan perintah pemeriksaan versi:

Untuk pengalaman pengodean yang optimal, tim inti Widya-Lang menyediakan ekstensi resmi Visual Studio Code yang mencakup penyorotan sintaksis kontekstual, pelengkapan kode cerdas (IntelliSense), cuplikan kode bawaan (snippets), dan pencocokan kurung blok otomatis:

  1. Buka aplikasi Visual Studio Code di komputer Anda.
  2. Buka panel Extensions dengan menekan tombol pintas Ctrl + Shift + X (atau Cmd + Shift + X di macOS).
  3. Klik tombol menu tiga titik (...) di sudut kanan atas panel ekstensi, lalu pilih menu Install from VSIX...

1.4 Perintah Tooling CLI Lengkap

Perkakas baris perintah Widya-Lang (widya) dirancang terpadu (all-in-one CLI) untuk menangani seluruh siklus hidup pengembangan perangkat lunak:

  • widya jalan <berkas.wya>: Menjalankan berkas kode sumber secara langsung dengan latensi startup instan.
  • widya repl: Membuka terminal interaktif (Read-Eval-Print Loop) untuk eksplorasi fungsi matematika, kueri database, atau verifikasi logika secara langsung baris demi baris.
  • widya kompilasi <berkas.wya> --keluaran <biner.exe>: Mengompilasi kode program menjadi berkas biner mandiri yang dapat langsung didistribusikan ke komputer pengguna akhir.
  • widya format <berkas.wya>: Memformat kode sumber secara otomatis sesuai panduan gaya penulisan resmi Widya-Lang.
  • widya tes: Menjalankan seluruh pengujian unit otomatis yang dideklarasikan di dalam proyek secara paralel.
  • widya paket <perintah>: Mengelola dependensi modul eksternal dan memaketkan artefak aplikasi ke format arsip terverifikasi.

2 Sistem Tipe Data Primitif, Mutabilitas & Operator

2.1 Filosofi Mutabilitas Data: `misal` vs `tetap`

Salah satu sumber galat terbesar dalam rekayasa perangkat lunak adalah modifikasi keadaan data yang tidak disengaja (unexpected mutation). Untuk mengatasi permasalahan ini sejak tingkat desain, Widya-Lang mewajibkan pemisahan tegas antara variabel dinamis yang boleh diubah nilainya dengan konstanta abadi yang nilainya terkunci mutlak:

  • misal (Mutable Variable): Digunakan untuk mendeklarasikan penampung data yang nilainya akan dimutasi sepanjang alur komputasi, seperti saldo transaksi, penghitung iterasi, akumulator total belanja, atau status koneksi jaringan.
  • tetap / tetapan (Immutable Constant): Digunakan untuk nilai absolut yang tidak boleh dimodifikasi sama sekali setelah inisialisasi awal. Setiap upaya memodifikasi konstanta akan langsung menghasilkan galat kompilasi sebelum program sempat dieksekusi.
// Deklarasi variabel dinamis yang dapat berubah
misal saldo_dompet = 150000;
saldo_dompet = saldo_dompet + 50000; // Valid! Nilai kini menjadi 200000

// Deklarasi konstanta yang terlindungi mutlak
tetap PERSENTASE_PPN = 0.11;
tetap KODE_NEGARA_ISO = "IDN";

// PERSENTASE_PPN = 0.12; 
// GALAT KOMPILASI W004: Simbol 'PERSENTASE_PPN' adalah tetapan dan nilainya tidak boleh diubah!

2.2 Model Memori: Alokasi Tumpukan (Stack) & Timbunan (Heap)

Widya-Lang mengelola memori secara otomatis dan deterministik. Tipe-tipe primitif dengan ukuran tetap (seperti bilangan bulat 64-bit, angka desimal, dan logika boolean) dialokasikan langsung pada Tumpukan (Stack) dengan kecepatan akses mikro-detik. Sementara itu, tipe data dinamis yang ukurannya dapat membesar (seperti Teks berpanjang dinamis, Deret, Kamus, dan Struktur Objek) disimpan di dalam Timbunan (Heap) dengan referensi penunjuk berhitung aman (reference counting & smart lifetime management). Hal ini mencegah kebocoran memori (memory leak) tanpa memerlukan penundaan pembersihan memori (stop-the-world garbage collection pause) yang mengganggu transaksi realtime.

2.4 Operator Lengkap Dialek Nusantara

misal x = 48;
misal y = 7;

// Operator Aritmatika Presisi
cetak("Penjumlahan (+)      :", x + y);  // 55
cetak("Pengurangan (-)      :", x - y);  // 41
cetak("Perkalian   (*)      :", x * y);  // 336
cetak("Pembagian Asli (/)   :", x / y);  // 6.857142857142857
cetak("Sisa Bagi Modulo (%) :", x % y);  // 6
cetak("Perpangkatan (^)     :", 2 ^ 8);  // 256

// Operator Perbandingan Relasional
cetak("Sama Dengan (==)     :", x == 48);  // benar
cetak("Tidak Sama (!=)      :", x != y);   // benar
cetak("Lebih Besar Dari (>) :", x > 100);  // salah
cetak("Lebih Kecil Sama (<=):", y <= 10);  // benar

// Operator Logika Alami Nusantara ('dan', 'atau', 'bukan')
misal punya_ktp = benar;
misal usia = 21;
misal masuk_daftar_hitam = salah;

misal layak_buka_rekening = punya_ktp dan (usia >= 17) dan (bukan masuk_daftar_hitam);
cetak("Kelayakan Membuka Rekening:", layak_buka_rekening); // benar

2.5 Konversi Tipe Data & Inspeksi Dinamis

Fungsi bawaan tipe(x) digunakan untuk memeriksa jenis data secara dinamis pada saat eksekusi (runtime). Untuk melakukan konversi eksplisit antar tipe data primitif, Widya-Lang menyediakan keluarga fungsi konversi terstandarisasi: 

misal input_teks_harga = "275000";
cetak("Tipe asli data        :", tipe(input_teks_harga)); // String

// Konversi Teks ke Angka Bulat
misal harga_bersih = ke_angka(input_teks_harga);
cetak("Tipe setelah konversi :", tipe(harga_bersih));     // Integer

// Konversi ke Teks & Desimal
misal total_pembayaran = harga_bersih * 1.11;
misal teks_struk = "Total Tagihan Final: Rp " + ke_teks(total_pembayaran);
cetak(teks_struk);

2.6 Manipulasi Bita (Bitwise Operations) & Sistem Masking Izin Akses

Operasi pada level bita sangat penting dalam rekayasa sistem berkinerja tinggi, protokol komunikasi jaringan biner, dan manajemen hak akses (Permission Masking): 

// Definisi bitmask izin akses sistem perbankan
tetap IZIN_BACA      = 1;  // 0001
tetap IZIN_TULIS     = 2;  // 0010
tetap IZIN_HAPUS     = 4;  // 0100
tetap IZIN_OTORISASI = 8;  // 1000

// Memberikan izin Baca + Tulis menggunakan operator OR (|)
misal hak_operator = IZIN_BACA | IZIN_TULIS; // 0011 = 3

// Memeriksa izin menggunakan operator AND (&)
misal boleh_tulis = (hak_operator & IZIN_TULIS) != 0;
misal boleh_hapus = (hak_operator & IZIN_HAPUS) != 0;

cetak("Hak Akses Tulis Operator :", boleh_tulis); // benar
cetak("Hak Akses Hapus Operator :", boleh_hapus); // salah

2.7 Manipulasi Teks Unicode & Ekstraksi Substring

3 Percabangan & Pola Perulangan Modern

3.1 Percabangan Bertingkat: `jika`, `kalau`, `lainnya`

Struktur kendali percabangan di Widya-Lang dievaluasi secara efisien dari blok atas ke bawah dengan teknik evaluasi sirkuit pendek (short-circuit evaluation). Blok kondisi pertama yang menghasilkan nilai logika benar akan dieksekusi secara instan, dan eksekutor langsung melompat keluar dari seluruh rangkaian percabangan tanpa mengevaluasi cabang-cabang berikutnya: 

misal nilai_skor_kredit = 785;
misal keputusan_analis = "";
misal plafon_pinjaman = 0;

jika nilai_skor_kredit >= 800 {
    keputusan_analis = "DISETUJUI_PRIORITAS_SUPER";
    plafon_pinjaman = 500000000;
} kalau nilai_skor_kredit >= 700 {
    keputusan_analis = "DISETUJUI_REGULER";
    plafon_pinjaman = 250000000;
} kalau nilai_skor_kredit >= 600 {
    keputusan_analis = "BUTUH_PENJAMIN_TAMBAHAN";
    plafon_pinjaman = 100000000;
} lainnya {
    keputusan_analis = "PERMOHONAN_DITOLAK";
    plafon_pinjaman = 0;
}

cetak("Hasil Analisis Resiko :", keputusan_analis);
cetak("Maksimal Plafon Kredit: Rp", plafon_pinjaman);

3.2 Perulangan Rentang Tertutup: `untuk` dalam `awal..akhir`

Widya-Lang menyediakan sintaksis rentang (range operator) yang sangat elegan dengan simbol dua titik berturut-turut (..). Rentang ini mengeksekusi iterasi terhitung dari batas awal hingga batas akhir secara inklusif tanpa memerlukan overhead alokasi memori deret: 

// Menghitung tabel perkalian komputasi
tetap BILANGAN_BASIS = 9;
cetak("=== TABEL PERKALIAN", BILANGAN_BASIS, "===");

untuk kali dalam 1..10 {
    misal hasil = BILANGAN_BASIS * kali;
    cetak(BILANGAN_BASIS, "x", kali, "=", hasil);
}

3.3 Iterasi Koleksi Elemen Deret

Ketika berhadapan dengan koleksi data dinamis, kata kunci untuk dapat langsung mengiterasi setiap elemen yang ada di dalam deret secara berurutan: 

misal komoditas_ekspor = ["Minyak Kelapa Sawit", "Nikel Olahan", "Kopi Robusta", "Karet Remah"];

cetak("Daftar Komoditas Ekspor Unggulan:");
untuk komoditas dalam komoditas_ekspor {
    cetak("• Produk Nasional:", komoditas);
}

3.4 Perulangan Kondisional `selama` & Kendali Alur (`henti`, `lanjut`)

Perulangan selama mengeksekusi blok kode berulang kali selama kondisi evaluasi bernilai benar. Untuk mengendalikan alur iterasi secara presisi, Widya-Lang menyediakan kata kunci henti (untuk memutus perulangan seketika) dan lanjut (untuk melompati sisa instruksi iterasi saat ini dan langsung melanjutkan ke iterasi berikutnya): 

misal penghitung = 0;
misal total_akumulasi = 0;

selama penghitung < 10 {
    penghitung = penghitung + 1;

    // Lewati bilangan kelipatan 2 (Genap)
    jika penghitung % 2 == 0 {
        lanjut;
    }

    // Hentikan proses jika nilai telah mencapai 7
    jika penghitung > 7 {
        henti;
    }

    total_akumulasi = total_akumulasi + penghitung;
    cetak("Memproses Bilangan Ganjil:", penghitung);
}

cetak("Total Akumulasi Terakhir :", total_akumulasi); // 1 + 3 + 5 + 7 = 16

3.5 Penerapan Algoritma Komputasi Riil: Pencarian Biner (Binary Search)

Untuk memahami efisiensi perulangan dan percabangan dalam menyelesaikan masalah nyata, perhatikan implementasi algoritma Pencarian Biner (Binary Search) berorde logaritmik $O(\log N)$ berikut: 

fungsi pencarian_biner(deret_angka, angka_target) {
    misal indeks_kiri = 0;
    misal indeks_kanan = panjang(deret_angka) - 1;

    selama indeks_kiri <= indeks_kanan {
        misal titik_tengah = ke_angka((indeks_kiri + indeks_kanan) / 2);
        misal nilai_tengah = deret_angka[titik_tengah];

        jika nilai_tengah == angka_target {
            kembalikan titik_tengah; // Ditemukan posisi indeks target
        } kalau nilai_tengah < angka_target {
            indeks_kiri = titik_tengah + 1;
        } lainnya {
            indeks_kanan = titik_tengah - 1;
        }
    }

    kembalikan -1; // Menandakan data tidak ditemukan
}

misal nomor_rekening_terurut = [1002, 1045, 1120, 1204, 1350, 1490, 1588, 1699];
misal target = 1490;
misal indeks_hasil = pencarian_biner(nomor_rekening_terurut, target);

cetak("Nomor Rekening", target, "ditemukan di slot indeks:", indeks_hasil); // 5

3.6 Algoritma Pengurutan Cepat (Quicksort O(N log N))

Quicksort adalah algoritma pengurutan data berbasis strategi bagi-dan-taklukkan (divide and conquer) yang sangat efisien untuk memproses jutaan rekaman data transaksi: 

fungsi pengurutan_quicksort(deret) {
    jika panjang(deret) <= 1 {
        kembalikan deret;
    }

    misal pivot = deret[0];
    misal kelompok_kiri = [];
    misal kelompok_sama = [];
    misal kelompok_kanan = [];

    untuk item dalam deret {
        jika item < pivot {
            tambah(kelompok_kiri, item);
        } kalau item == pivot {
            tambah(kelompok_sama, item);
        } lainnya {
            tambah(kelompok_kanan, item);
        }
    }

    misal urut_kiri = pengurutan_quicksort(kelompok_kiri);
    misal urut_kanan = pengurutan_quicksort(kelompok_kanan);

    kembalikan gabung_deret(urut_kiri, kelompok_sama, urut_kanan);
}

misal nilai_acak = [85, 24, 63, 45, 17, 31, 96, 50];
misal nilai_terurut = pengurutan_quicksort(nilai_acak);
cetak("Hasil Quicksort Nusantara:", nilai_terurut);

4 Fungsi, Rekursi & Paradigma Fungsional

4.1 Deklarasi Fungsi, Ruang Lingkup & Nilai Balik

Fungsi merupakan unit modularitas dasar di Widya-Lang yang membungkus serangkaian instruksi komputasi ke dalam blok bernama. Fungsi dapat menerima nol atau lebih parameter dan mengembalikan nilai komputasi melalui instruksi kembalikan (atau return): 

fungsi hitung_anuitas_bulanan(pokok_kredit, suku_bunga_tahunan, tenor_bulan) {
    misal suku_bunga_bulanan = (suku_bunga_tahunan / 100) / 12;
    misal faktor_pangkat = (1 + suku_bunga_bulanan) ^ tenor_bulan;
    misal besaran_angsuran = pokok_kredit * (suku_bunga_bulanan * faktor_pangkat) / (faktor_pangkat - 1);
    
    kembalikan ke_angka(besaran_angsuran);
}

misal angsuran_kpr = hitung_anuitas_bulanan(350000000, 8.25, 120);
cetak("Estimasi Angsuran KPR Bulanan: Rp", angsuran_kpr);

4.2 Pengembalian Nilai Jamak (Multiple Return Values)

Widya-Lang mendukung pengembalian nilai jamak menggunakan struktur kamus atau deret secara langsung, memudahkan kalkulasi simultan tanpa memerlukan variabel global: 

fungsi kalkulasi_statistik_dasar(deret_angka) {
    misal jumlah_total = 0;
    misal nilai_min = deret_angka[0];
    misal nilai_maks = deret_angka[0];
    misal n = panjang(deret_angka);

    untuk val dalam deret_angka {
        jumlah_total = jumlah_total + val;
        jika val < nilai_min { nilai_min = val; }
        jika val > nilai_maks { nilai_maks = val; }
    }

    misal rerata = jumlah_total / n;

    kembalikan {
        "total": jumlah_total,
        "rerata": rerata,
        "terendah": nilai_min,
        "tertinggi": nilai_maks
    };
}

misal hasil_analisis = kalkulasi_statistik_dasar([85, 92, 74, 98, 65, 90]);
cetak("Rata-rata Nilai Kelas:", hasil_analisis["rerata"]);
cetak("Nilai Tertinggi Siswa :", hasil_analisis["tertinggi"]);

4.3 Rekursi Kompleks: Algoritma Menara Hanoi

Widya-Lang mengeksekusi fungsi rekursif dengan alokasi bingkai tumpukan (stack frame) yang aman dan presisi. Berikut adalah implementasi algoritma legendaris Menara Hanoi untuk memindahkan cakram komputasi antar tiang: 

fungsi pindahkan_hanoi(jumlah_cakram, tiang_asal, tiang_tujuan, tiang_bantuan) {
    jika jumlah_cakram == 1 {
        cetak("Pindahkan Cakram 1 dari", tiang_asal, "ke", tiang_tujuan);
        kembalikan 1;
    }

    misal langkah1 = pindahkan_hanoi(jumlah_cakram - 1, tiang_asal, tiang_bantuan, tiang_tujuan);
    cetak("Pindahkan Cakram", jumlah_cakram, "dari", tiang_asal, "ke", tiang_tujuan);
    misal langkah2 = pindahkan_hanoi(jumlah_cakram - 1, tiang_bantuan, tiang_tujuan, tiang_asal);

    kembalikan langkah1 + 1 + langkah2;
}

cetak("--- ALGORITMA MENARA HANOI (3 CAKRAM) ---");
misal total_langkah = pindahkan_hanoi(3, "Tiang-A", "Tiang-C", "Tiang-B");
cetak("Total Langkah Pemindahan Selesai:", total_langkah); // 7 langkah

4.4 Paradigma Fungsional: `petakan`, `saring`, dan `lipat`

Widya-Lang mengadopsi fungsi tingkat tinggi (higher-order functions) sebagai warga kelas satu (first-class citizen). Anda dapat melewatkan fungsi sebagai parameter untuk memproses data tanpa efek samping (pure transformations): 

misal nominal_transaksi = [25000, 45000, 120000, 85000, 350000, 15000];

// 1. Saring (Filter): Ambil transaksi dengan nominal di atas Rp 50.000
fungsi kriteria_signifikan(x) {
    kembalikan x >= 50000;
}
misal transaksi_besar = saring(nominal_transaksi, kriteria_signifikan);
cetak("Transaksi Signifikan:", transaksi_besar); // [120000, 85000, 350000]

// 2. Petakan (Map): Berikan diskon cashback 5% pada transaksi terpilih
fungsi hitung_cashback(x) {
    kembalikan ke_angka(x * 0.05);
}
misal daftar_cashback = petakan(transaksi_besar, hitung_cashback);
cetak("Cashback Diterima    :", daftar_cashback); // [6000, 4250, 17500]

// 3. Lipat (Reduce/Fold): Hitung total akumulasi cashback yang dikeluarkan
fungsi akumulasikan(total_sekarang, item_berikutnya) {
    kembalikan total_sekarang + item_berikutnya;
}
misal total_beban_cashback = lipat(daftar_cashback, akumulasikan, 0);
cetak("Total Beban Cashback :", total_beban_cashback); // 27750

4.5 Rekursi Ekor (Tail Call Optimization / TCO)

Ketika fungsi memanggil dirinya sendiri di baris paling akhir eksekusi (tail position), kompiler Widya-Lang secara otomatis mengoptimalkan pemanggilan tersebut menjadi loop iteratif tanpa menambah bingkai tumpukan memori (Zero Stack Overhead), menjamin keamanan komputasi dari galat Stack Overflow: 

// Faktorial dengan akumulator tail-recursive
fungsi faktorial_tco(n, akumulator) {
    jika n <= 1 {
        kembalikan akumulator;
    }
    kembalikan faktorial_tco(n - 1, n * akumulator);
}

cetak("Faktorial 20 (Aman Stack):", faktorial_tco(20, 1));

4.6 Operator Pipeline (`|>`) Komposisi Data

// Transformasi data fungsional dari kiri ke kanan dengan operator pipeline
misal hasil_pipeline = [10, 25, 40, 55, 70]
    |> saring(fungsi(x) { kembalikan x > 30; })
    |> petakan(fungsi(x) { kembalikan x * 2; });

cetak("Hasil Transformasi Pipeline:", hasil_pipeline); // [80, 110, 140]
