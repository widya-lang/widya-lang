15.1 Kriptografi Pasca-Kuantum (Post-Quantum Cryptography: ML-KEM / Kyber-768)

Perkembangan komputer kuantum di masa depan berpotensi meruntuhkan sistem enkripsi RSA dan kurva eliptis klasik. Widya-Lang adalah salah satu pelopor bahasa berdaulat yang telah mengintegrasikan modul pertukaran kunci berbasis kekisi (lattice-based cryptography) standar NIST ML-KEM (Kyber-768) di dalam modul/kripto_aman.wya: 

impor "./modul/kripto_aman.wya";

fungsi pertukaran_kunci_kuantum() {
    // 1. Penerima (Server Bank) Membangkitkan Pasangan Kunci Kyber-768
    misal kunci_server = BuatPasanganKunciKyber768();
    cetak("Kunci Publik Kuantum Server (1184 Bita):", panjang(kunci_server.publik));

    // 2. Pengirim (Aplikasi Nasabah) Melakukan Enkapsulasi Kunci Bersama
    misal enkapsulasi = EnkapsulasiKyber768(kunci_server.publik);
    // enkapsulasi menghasilkan: ciphertext (1088 bita) dan kunci_bersama (32 bita)

    // 3. Penerima Melakukan Dekapsulasi Kunci Bersama dengan Kunci Privat
    misal kunci_terdekapsulasi = DekapsulasiKyber768(enkapsulasi.ciphertext, kunci_server.privat);

    // Verifikasi kedua pihak memiliki kunci rahasia simetris yang identik
    misal aman = perbandingan_waktu_konstan(enkapsulasi.kunci_bersama, kunci_terdekapsulasi);
    cetak("Kunci Bersama Kuantum Sukses Disepakati:", aman); // benar
}

15.2 Perbandingan Waktu Konstan (Constant-Time Comparison)

Serangan waktu (timing attacks) memanfaatkan perbedaan mikro-detik dalam pembandingan string untuk menebak sandi atau token. Widya-Lang menyediakan fungsi pembandingan yang kebal terhadap kebocoran waktu komputasi: 

fungsi perbandingan_waktu_konstan(teks_a, teks_b) {
    jika panjang(teks_a) != panjang(teks_b) {
        kembalikan salah;
    }
    misal akumulasi_xor = 0;
    misal n = panjang(teks_a);
    untuk i dalam 0..(n - 1) {
        akumulasi_xor = akumulasi_xor | (kode_karakter(teks_a, i) ^ kode_karakter(teks_b, i));
    }
    kembalikan akumulasi_xor == 0;
}

16.1 Pengujian Berbasis Properti (Property-Based Testing)

Selain pengujian kasus unit statis, pengujian berbasis properti menguji apakah invarian logika matematis tetap berlaku di bawah ribuan masukan acak: 

impor "./modul/pengujian.wya";

tes_properti "Invarian: Komutatif Penjumlahan Selalu Berlaku" {
    uji_untuk_semua(tipe_data_acak("angka"), tipe_data_acak("angka"), fungsi(a, b) {
        pastikan_sama(a + b, b + a);
    });
}

tes_properti "Invarian: Enkripsi yang Diikuti Dekripsi Mengembalikan Nilai Asli" {
    uji_untuk_semua(tipe_data_acak("teks"), fungsi(pesan_asli) {
        misal sandi = EnkripsiAES256GCM(pesan_asli, KUNCI_UJI);
        misal balik = DekripsiAES256GCM(sandi.ciphertext, KUNCI_UJI, sandi.nonce, sandi.tag);
        pastikan_sama(pesan_asli, balik);
    });
}
