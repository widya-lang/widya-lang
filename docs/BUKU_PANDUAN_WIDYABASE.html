i Kata Pengantar

Selamat datang di dunia WidyaBase! Jika Anda adalah seorang pemrogram pemula, mahasiswa ilmu komputer, atau pengembang aplikasi yang ingin memahami bagaimana basis data relasional bekerja dari dasar, buku ini ditulis khusus untuk Anda.

Selama puluhan tahun, pemrogram di Indonesia mempelajari SQL dengan kata kunci berbahasa Inggris (seperti CREATE TABLE, SELECT, INSERT INTO). WidyaBase hadir dengan terobosan unik: Mesin Basis Data Mandiri Dwibahasa Simetris Pertama di Dunia. Anda dapat menulis kueri menggunakan bahasa ibu kita—Bahasa Indonesia yang alami (seperti BUAT_TABEL, PILIH, SISIP_KE)—maupun standar internasional ANSI SQL tanpa perbedaan performa seperseribu detik pun.

Lebih dari sekadar kueri yang ramah pemula, WidyaBase dirancang dengan standar arsitektur kelas industri yang sesungguhnya:

  • Slotted-Page Storage 4KB: Standar manajemen disk berkinerja tinggi yang digunakan oleh mesin enterprise seperti PostgreSQL dan Oracle.
  • Write-Ahead Logging (WAL): Menjamin transaksi bisnis tidak akan pernah hilang walaupun listrik padam tiba-tiba.
  • MVCC (Multi-Version Concurrency Control): Membaca dan menulis data secara bersamaan tanpa saling mengunci (non-blocking).
  • PostgreSQL Wire Protocol v3.0: Server daemon TCP mandiri sehingga aplikasi luar (DBeaver, Python, Node.js) dapat terhubung seketika.

01 Mengenal WidyaBase & Filosofi Basis Data

1.1 Mengapa Kita Membutuhkan Basis Data?

Bayangkan Anda memiliki sebuah toko kelontong atau kafe kopi. Pada hari pertama, Anda mencatat setiap penjualan di buku kas kertas. Ketika toko Anda semakin ramai dan transaksi mencapai ribuan per hari, mencatat di kertas menjadi lambat, rawan hilang, dan sulit dicari.

Anda mungkin mencoba menggunakan aplikasi spreadsheet seperti Microsoft Excel atau Google Sheets. Spreadsheet sangat bagus untuk laporan sederhana, namun memiliki kelemahan besar ketika dipakai oleh aplikasi:

  • Konkurensi Buruk: Jika 5 kasir menyimpan transaksi pada detik yang sama, spreadsheet rawan bertabrakan (*file conflict*).
  • Tidak Tahan Bencana: Jika komputer tiba-tiba mati listrik saat menyimpan, file spreadsheet bisa rusak (*corrupt*).
  • Kecepatan Terbatas: Mencari 1 data di antara 1 juta baris membutuhkan pemindaian dari awal hingga akhir (*slow full scan*).

Di sinilah Basis Data Relasional (RDBMS) dibutuhkan. Basis data adalah perangkat lunak khusus yang dirancang untuk menyimpan, mengamankan, dan menyajikan jutaan data dalam hitungan milidetik secara konkuren dan tahan banting.

1.2 Apa itu WidyaBase?

WidyaBase adalah mesin basis data relasional mandiri (*autonomous relational database engine*) yang diciptakan sebagai bagian dari ekosistem bahasa pemrograman Widya. WidyaBase dikompilasi menjadi satu file biner mandiri (WidyaBase.exe) tanpa memerlukan instalasi software pihak ketiga yang rumit.

ℹ️ Konsep File Tunggal WidyaBase
Saat Anda membuat basis data di WidyaBase, semua tabel dan data Anda disimpan dalam satu file biner berekstensi .wdb (misalnya toko.wdb), ditemani oleh satu file log transaksi .wal (misalnya toko.wal). Anda cukup menyalin file ini untuk memindahkan seluruh basis data Anda!

1.3 Ciri Khas: SQL Dwibahasa Simetris

Keunikan utama WidyaBase adalah fleksibilitas bahasanya. Anda bebas memilih gaya penulisan yang paling Anda sukai:

Tindakan Basis Data Dialek Nusantara (Bahasa Indonesia) Standar Global (ANSI SQL)
Membuat Tabel BUAT_TABEL produk (...); CREATE TABLE produk (...);
Menyisipkan Data SISIP_KE produk NILAI (...); INSERT INTO produk VALUES (...);
Mengambil Data PILIH * DARI produk; SELECT * FROM produk;
Menyaring Data ... DIMANA harga > 20000; ... WHERE harga > 20000;
Mengurutkan Data ... URUTKAN BERDASARKAN harga TURUN; ... ORDER BY harga DESC;

02 Instalasi & Memulai Konsol Interaktif (REPL)

2.1 Menyiapkan Berkas Eksekusi

WidyaBase didistribusikan dalam bentuk biner portabel. Anda tidak perlu mengonfigurasi service Windows atau dependensi runtime C++ tambahan.

  1. Letakkan berkas WidyaBase.exe pada folder kerja Anda (misalnya C:\proyek\).
  2. Buka terminal favorit Anda (Command Prompt atau PowerShell).
  3. Periksa apakah WidyaBase siap dijalankan dengan mengetikkan:
# Memeriksa versi dan bantuan WidyaBase
.WidyaBase.exe --help

Anda akan melihat layar sambutan resmi WidyaBase beserta daftar perintah yang tersedia.

2.2 Membuka Konsol Interaktif (REPL)

Cara tercepat bagi pemula untuk belajar adalah masuk ke mode REPL (Read-Eval-Print Loop). Mode ini memungkinkan Anda mengetikkan kueri SQL dan melihat hasilnya seketika pada layar terminal. 

# Masuk ke REPL dengan basis data 'toko.wdb'
.WidyaBase.exe --data toko.wdb sql

Terminal Anda akan berubah menjadi konsol interaktif WidyaBase: 

🗄️  Konsol SQL Interaktif WidyaBase v1.0.0
Basis Data: toko.wdb | Protokol: Dwibahasa Simetris
Ketik '.bantuan' untuk panduan perintah atau '.keluar' untuk selesai.

widyabase> _

2.3 Perintah Bantuan Konsol (Dot Commands)

Di dalam REPL, terdapat perintah praktis berawalan tanda titik (.) untuk mengelola sesi Anda:

  • .bantuan : Menampilkan panduan kueri dan sintaksis.
  • .tabel : Menampilkan daftar seluruh tabel yang ada di dalam database.
  • .skema <nama_tabel> : Melihat struktur kolom dan tipe data dari suatu tabel.
  • .status : Memeriksa kesehatan mesin, total halaman disk, dan log transaksi.
  • .keluar : Menyimpan dan menutup sesi konsol.
🎯 Latihan Mandiri 2.1
Buka terminal Anda, jalankan .WidyaBase.exe sql, lalu ketikkan .status. Perhatikan informasi status buffer pool dan halaman yang ditampilkan pada konsol Anda!

03 Mendesain & Membuat Tabel Pertama (DDL)

3.1 Memahami Konsep Tabel, Kolom, dan Baris

Dalam basis data relasional, data disimpan dalam bentuk Tabel. Analoginya persis seperti sebuah lembar kerja:

  • Kolom (Column / Field): Menentukan jenis atribut apa yang disimpan (misal: ID, Nama Produk, Harga).
  • Baris (Row / Record): Satu data utuh yang mewakili satu objek nyata (misal: Produk ID 1 bernama 'Kopi Gayo' seharga 35.000).
  • Kunci Utama (Primary Key): Kolom khusus yang nilainya wajib unik dan tidak boleh kembar untuk setiap baris.

3.2 Tipe Data Dasar WidyaBase

Sebelum membuat kolom, kita harus menentukan tipe datanya:

Tipe Data (Nusantara) Tipe Data (ANSI) Penjelasan & Contoh Penggunaan
INT atau BULAT INT / INTEGER Bilangan bulat tanpa koma desimal (Contoh: ID, stok barang, jumlah).
TEKS TEXT / VARCHAR Rangkaian karakter atau kalimat teks (Contoh: nama barang, alamat, surel).
ANGKA NUMERIC / FLOAT Bilangan dengan angka desimal atau pecahan mata uang (Contoh: harga, diskon).
LOGIKA BOOLEAN Nilai kebenaran (Hanya dapat bernilai TRUE / BENAR atau FALSE / SALAH).

3.3 Perintah Membuat Tabel: BUAT_TABEL

Mari kita buat tabel pertama bernama menu_kopi. Di dalam REPL, ketikkan kueri berikut lalu tekan Enter: 

BUAT_TABEL menu_kopi (
    id INT KUNCI_UTAMA,
    nama TEKS,
    harga ANGKA,
    tersedia LOGIKA
);

WidyaBase akan merespons dengan: 

✅ Tabel 'menu_kopi' berhasil dibuat (Root Page: 1)
💡 Setara dengan Standar Global ANSI SQL
Kueri di atas memiliki makna yang sama persis jika Anda menuliskan:
CREATE TABLE menu_kopi (id INT PRIMARY KEY, nama TEXT, harga NUMERIC, tersedia BOOLEAN);

3.4 Menghapus Tabel: HAPUS_TABEL

Jika Anda membuat kesalahan desain tabel dan ingin menghapusnya, gunakan perintah: 

HAPUS_TABEL menu_kopi;

04 Menyisipkan Data ke Basis Data (DML - Insert)

4.1 Perintah SISIP_KE (Insert)

Setelah tabel terbentuk, tabel tersebut masih kosong. Untuk memasukkan baris data ke dalam tabel, kita menggunakan perintah SISIP_KE (atau INSERT INTO dalam standar ANSI).

Sintaks Dasar:

SISIP_KE <nama_tabel> (<kolom1>, <kolom2>, ...) NILAI (<nilai1>, <nilai2>, ...);

4.2 Memasukkan Data Praktik

Mari kita masukkan beberapa menu kopi ke dalam tabel menu_kopi yang telah kita buat: 

-- Memasukkan menu pertama
SISIP_KE menu_kopi (id, nama, harga, tersedia) 
NILAI (1, 'Kopi Tubruk Gayo', 25000, BENAR);

-- Memasukkan menu kedua
SISIP_KE menu_kopi (id, nama, harga, tersedia) 
NILAI (2, 'Es Kopi Susu Aren', 22000, BENAR);

-- Memasukkan menu ketiga
SISIP_KE menu_kopi (id, nama, harga, tersedia) 
NILAI (3, 'Manual Brew Toraja', 32000, BENAR);

-- Memasukkan menu keempat (stok habis / tidak tersedia)
SISIP_KE menu_kopi (id, nama, harga, tersedia) 
NILAI (4, 'Cold Brew Flores', 35000, SALAH);

4.3 Aturan Penulisan Nilai untuk Pemula

  • Nilai Teks: Wajib diapit dengan tanda petik tunggal ('Kopi Gayo'). Jangan gunakan tanda petik ganda untuk nilai teks.
  • Nilai Angka / Numerik: Ditulis langsung tanpa tanda petik (25000). Jika mengandung desimal, gunakan tanda titik (18500.50).
  • Nilai Boolean: Tuliskan BENAR atau SALAH (dalam standar ANSI: TRUE atau FALSE).
⚠️ Perhatian: Duplikasi Kunci Utama
Karena kolom id didefinisikan sebagai KUNCI_UTAMA, Anda tidak boleh memasukkan dua baris yang memiliki nilai id yang sama! Kunci utama menjamin setiap baris dapat diidentifikasi secara unik.

05 Membaca, Menyaring & Mengurutkan Data (DQL - Select)

5.1 Mengambil Semua Data: PILIH *

Perintah PILIH (atau SELECT) adalah perintah yang paling sering digunakan dalam pengelolaan basis data. Tanda bintang (*) berarti kita ingin menampilkan seluruh kolom yang ada. 

PILIH * DARI menu_kopi;

Keluaran di konsol terminal Anda:

+----+--------------------+-------+----------+
| ID | NAMA               | HARGA | TERSEDIA |
+----+--------------------+-------+----------+
| 1  | Kopi Tubruk Gayo   | 25000 | true     |
| 2  | Es Kopi Susu Aren  | 22000 | true     |
| 3  | Manual Brew Toraja | 32000 | true     |
| 4  | Cold Brew Flores   | 35000 | false    |
+----+--------------------+-------+----------+
(4 baris ditampilkan)

5.2 Memilih Kolom Spesifik & Memberi Nama Alias (SEBAGAI)

Daripada mengambil semua kolom, kita dapat memilih kolom tertentu saja, dan memberikan judul kolom yang lebih ramah pengguna menggunakan kata kunci SEBAGAI (atau AS): 

PILIH nama SEBAGAI nama_menu, harga SEBAGAI harga_satuan 
DARI menu_kopi;

5.3 Menyaring Data dengan Kondisi: DIMANA (Where)

Seringkali kita hanya ingin melihat data yang memenuhi kriteria tertentu. Kita menggunakan klausa DIMANA (atau WHERE): 

-- Cari kopi yang harganya di bawah 30.000
PILIH nama, harga 
DARI menu_kopi 
DIMANA harga < 30000;

Operator Pembanding yang Didukung:

OperatorArtiContoh
=Sama denganDIMANA id = 2
!=Tidak sama denganDIMANA tersedia != SALAH
> / <Lebih besar / Lebih kecilDIMANA harga > 25000
>= / <=Lebih besar sama dengan / Lebih kecil sama denganDIMANA harga >= 32000
DAN / ANDKedua kondisi harus terpenuhiDIMANA harga > 20000 DAN harga < 30000
ATAU / ORSalah satu kondisi terpenuhiDIMANA id = 1 ATAU id = 3

5.4 Mengurutkan Data: URUTKAN BERDASARKAN (Order By)

Untuk mengurutkan data dari yang paling murah ke paling mahal (atau sebaliknya):

  • NAIK (atau ASC): Dari kecil ke besar / A ke Z.
  • TURUN (atau DESC): Dari besar ke kecil / Z ke A.
-- Mengurutkan kopi dari harga tertinggi ke terendah
PILIH nama, harga 
DARI menu_kopi 
URUTKAN BERDASARKAN harga TURUN;

5.5 Membatasi Jumlah Data: BATAS & LEWATI (Limit & Offset)

Fitur ini sangat penting saat Anda membuat halaman aplikasi web (*pagination*): 

-- Ambil 2 menu termahal saja (Top 2)
PILIH nama, harga 
DARI menu_kopi 
URUTKAN BERDASARKAN harga TURUN 
BATAS 2;

5.6 Relasi Antar-Tabel: GABUNG (Join) & Optimasi Index Scan

Di dunia nyata, data sering terpisah di beberapa tabel yang saling berhubungan (misal: tabel pesanan dan tabel pelanggan). WidyaBase mendukung kueri relasional GABUNG (atau JOIN) secara dwibahasa: 

-- Menggabungkan tabel pesanan dengan tabel pelanggan
PILIH pesanan.id, pelanggan.nama, pesanan.total 
DARI pesanan 
GABUNG pelanggan PADA pesanan.pelanggan_id = pelanggan.id 
DIMANA pesanan.total >= 50000 
URUTKAN BERDASARKAN pesanan.total TURUN;
⚡ Optimasi Index Scan B+Tree Otomatis
Jika kueri Anda mencari data spesifik berdasarkan Kunci Utama (contoh: DIMANA id = 10), mesin WidyaBase secara otomatis mengalihkan eksekusi ke pemindaian pohon B+Tree $O(log N)$ berkecepatan mikrodetik tanpa perlu memindai seluruh baris tabel secara sekuensial!

06 Mengubah & Menghapus Data Secara Aman (Update & Delete)

6.1 Memperbarui Data: PERBARUI ... ATUR (Update)

Data di dunia nyata selalu berubah: harga barang naik, stok berganti, atau status ketersediaan berubah. Untuk memperbarui data yang sudah ada, gunakan PERBARUI (atau UPDATE):

Sintaks:

PERBARUI <nama_tabel> ATUR <kolom> = <nilai_baru> DIMANA <kondisi>;

Contoh Praktik:

Misalkan harga menu 'Kopi Tubruk Gayo' (ID = 1) naik menjadi 28.000:

PERBARUI menu_kopi 
ATUR harga = 28000 
DIMANA id = 1;

WidyaBase akan menampilkan respon: affected: 1 (1 baris berhasil diubah).

6.2 Menghapus Data: HAPUS_DARI (Delete)

Jika suatu item ingin dihapus secara permanen dari tabel, gunakan perintah HAPUS_DARI (atau DELETE FROM): 

-- Menghapus menu dengan ID = 4
HAPUS_DARI menu_kopi DIMANA id = 4;
🚨 ATURAN EMAS PEMULA: Selalu Sertakan Klausa DIMANA!
Jika Anda menjalankan perintah: PERBARUI menu_kopi ATUR harga = 10000; tanpa klausa DIMANA, maka SEMUA harga kopi di warung Anda akan berubah menjadi 10.000!

Begitu pula jika Anda mengetik HAPUS_DARI menu_kopi; tanpa DIMANA, seluruh data tabel akan terhapus bersih. Selalu berhati-hati dan teliti sebelum menekan Enter!

07 Fungsi Agregasi & Analitik Data Penjualan

7.1 Apa itu Fungsi Agregasi?

Seringkali pemilik bisnis tidak butuh melihat daftar jutaan baris transaksi satu per satu, melainkan angka ringkasan eksekutif: Berapa banyak transaksi hari ini? Berapa total omzet penjualan? Berapa harga rata-rata produk kita?

WidyaBase menyediakan 5 fungsi agregasi bilingual terintegrasi:

Fungsi (Nusantara) Fungsi (ANSI) Kegunaan
HITUNG(*) COUNT(*) Menghitung jumlah total baris data yang ditemukan.
JUMLAH(kolom) SUM(kolom) Menjumlahkan seluruh total nilai angka pada suatu kolom.
RATA_RATA(kolom) AVG(kolom) Menghitung rata-rata nilai numerik pada suatu kolom.
MIN(kolom) MIN(kolom) Mencari nilai terkecil / terendah pada suatu kolom.
MAKS(kolom) MAX(kolom) Mencari nilai terbesar / tertinggi pada suatu kolom.

7.2 Studi Kasus: Laporan Eksekutif Toko Kopi

Mari kita buat kueri analitik komprehensif terhadap tabel menu_kopi: 

PILIH 
    HITUNG(*) SEBAGAI total_menu,
    JUMLAH(harga) SEBAGAI total_nilai_menu,
    RATA_RATA(harga) SEBAGAI harga_rata_rata,
    MIN(harga) SEBAGAI harga_termurah,
    MAKS(harga) SEBAGAI harga_termahal
DARI menu_kopi;

Hasil yang ditampilkan:

+------------+------------------+-----------------+---------------+---------------+
| TOTAL_MENU | TOTAL_NILAI_MENU | HARGA_RATA_RATA | HARGA_TERMURAH| HARGA_TERMAHAL|
+------------+------------------+-----------------+---------------+---------------+
| 3          | 82000.0          | 27333.33        | 22000.0       | 32000.0       |
+------------+------------------+-----------------+---------------+---------------+
(1 baris ringkasan analitik)

Hanya dengan satu baris kueri yang mudah dibaca, Anda langsung mendapatkan laporan metrik finansial bisnis yang akurat!

08 Transaksi ACID & Perlindungan Data dari Crash

8.1 Skenario Nyata: Mengapa Kita Butuh Transaksi?

Bayangkan skenario transfer uang di bank: Budi ingin mentransfer Rp 50.000 ke rekening Siti.

  1. Langkah 1: Saldo Budi dikurangi Rp 50.000.
  2. Langkah 2: Saldo Siti ditambah Rp 50.000.

Apa yang terjadi jika saat Langkah 1 selesai, server tiba-tiba mati listrik atau kabel tercabut sebelum Langkah 2 dieksekusi? Uang Budi sudah terpotong, tetapi uang belum sampai ke Siti! Uang hilang di antah berantah.

Inilah mengapa kita memerlukan Transaksi ACID. Dalam sebuah transaksi, seluruh rangkaian langkah diperlakukan sebagai satu kesatuan utuh: semua harus berhasil bersama-sama, atau jika ada satu kegagalan, semuanya dibatalkan seperti tidak pernah terjadi (*All or Nothing*).

8.2 Memahami Konsep ACID untuk Pemula

  • Atomicity (Keutuhan): Transaksi tidak dapat dibagi-bagi. Harus komit seutuhnya atau dibatalkan seutuhnya.
  • Consistency (Konsistensi): Data selalu valid sesuai aturan skema dan kunci utama.
  • Isolation (Isolasi MVCC): Transaksi satu tidak terganggu oleh transaksi lain yang sedang berjalan bersamaan.
  • Durability (Ketahanan): Begitu transaksi dikonfirmasi (Commit), data dijamin tersimpan permanen di disk melalui Write-Ahead Log (WAL).

8.3 Perintah Transaksi di WidyaBase

-- 1. Memulai Transaksi
MULAI TRANSAKSI; -- atau: BEGIN TRANSACTION;

-- 2. Melakukan beberapa operasi
SISIP_KE menu_kopi (id, nama, harga, tersedia) NILAI (10, 'Kopi Promo', 10000, BENAR);
PERBARUI menu_kopi ATUR harga = 12000 DIMANA id = 10;

-- 3A. Jika semua berhasil: Simpan secara permanen
KOMIT; -- atau: COMMIT;

-- 3B. Jika terjadi kesalahan: Batalkan seluruh perubahan
-- BATALKAN; -- atau: ROLLBACK;

09 Menghubungkan DBeaver, Python, Node.js & Bahasa Widya

9.1 Menjalankan Server Jaringan (pgwire v3.0)

Salah satu keunggulan terbesar WidyaBase adalah kemampuannya bertindak sebagai PostgreSQL-compatible server. Anda dapat menjalankan WidyaBase sebagai service jaringan TCP: 

# Menjalankan server WidyaBase pada port default 5432
.WidyaBase.exe --data toko.wdb mulai --port 5432

WidyaBase akan menampilkan log:

🚀 [WidyaBase] Server aktif mendengarkan di 0.0.0.0:5432 (pgwire v3.0)

9.2 Menghubungkan DBeaver / TablePlus (GUI Client)

Anda dapat menggunakan aplikasi manajemen visual database seperti DBeaver atau TablePlus untuk melihat tabel secara grafis:

  1. Buka DBeaver, pilih New Database Connection -> PostgreSQL.
  2. Isi Host: localhost, Port: 5432, Database: toko.
  3. Username: postgres (atau bebas), Password: biarkan kosong.
  4. Klik Test Connection -> Sukses! Anda sekarang dapat menjelajahi tabel secara visual.

9.3 Menghubungkan dari Aplikasi Python

Gunakan library standar psycopg2 di Python:

import psycopg2

# Hubungkan ke WidyaBase
conn = psycopg2.connect(
    host="localhost",
    port=5432,
    database="toko",
    user="postgres"
)
cursor = conn.cursor()

# Anda bisa mengirimkan kueri berbahasa Indonesia!
cursor.execute("PILIH nama, harga DARI menu_kopi URUTKAN BERDASARKAN harga TURUN;")
for baris in cursor.fetchall():
    print(f"Menu: {baris[0]} | Harga: Rp {baris[1]:,}")

cursor.close()
conn.close()

9.4 Menghubungkan secara Native dari Bahasa Pemrograman Widya

Di dalam bahasa pemrograman Widya (.wya), WidyaBase terintegrasi secara asli tanpa perlu driver jaringan: 

fungsi utama() {
    tetapkan db = WidyaBase.buka("toko.wdb");
    tetapkan hasil = db.eksekusi("PILIH nama, harga DARI menu_kopi;");
    
    cetak("Data Menu Kopi:");
    untuk baris dalam hasil.baris {

10 Backup, Ekspor & Impor Data (CSV, JSON, SQL Dump)

10.1 Mengapa Backup Data itu Wajib?

Di dunia industri teknologi, data adalah aset yang paling berharga. Kegagalan perangkat keras hard disk, kesalahan manusia (*human error*), atau serangan siber dapat terjadi kapan saja. Oleh karena itu, kemampuan mengekspor dan mengimpor data merupakan keterampilan wajib bagi setiap pengembang.

10.2 Ekspor Data ke Format CSV (Untuk Microsoft Excel)

CSV (Comma-Separated Values) adalah format pertukaran data paling umum yang dapat langsung dibuka oleh akuntan di Microsoft Excel: 

# Ekspor data tabel ke file CSV
.WidyaBase.exe --data toko.wdb --format csv kueri "PILIH * DARI menu_kopi;" > menu_kopi.csv

10.3 Ekspor Data ke Format JSON (Untuk Web / Mobile API)

Jika Anda membangun aplikasi frontend berbasis React, Vue, Flutter, atau mobile app, Anda memerlukan format JSON: 

# Ekspor data tabel ke file JSON
.WidyaBase.exe --data toko.wdb --format json kueri "PILIH * DARI menu_kopi;" > menu_kopi.json

10.4 Membuat SQL Dump & Memulihkan Basis Data (Restore)

Untuk mencadangkan seluruh struktur dan isi basis data ke dalam skrip SQL teks yang dapat dijalankan ulang di komputer mana pun: 

# Membaca skrip SQL dump ke dalam basis data baru
Get-Content backup_toko.sql | .WidyaBase.exe --data toko_baru.wdb kueri -

10.5 Memeriksa Integritas Database: periksa

Untuk memastikan file basis data Anda sehat, tidak ada halaman disk yang rusak, dan seluruh log WAL sinkron: 

.WidyaBase.exe --data toko.wdb periksa

Keluaran laporan kesehatan:

• Total Halaman Aktif  : 3 Halaman (12,288 Byte)
• Total Tabel Terdaftar: 1 Tabel

11 Pengantar Fitur Canggih: Vektor AI & JSONB

11.1 Basis Data di Era Kecerdasan Buatan (AI)

Basis data modern tidak hanya menyimpan angka dan teks sederhana. Di era Large Language Models (LLM) seperti ChatGPT, Gemini, dan Claude, kita sering bekerja dengan Vektor Embedding—representasi makna kata dalam bentuk deretan angka float.

11.2 Menghitung Kemiripan Kosinus (Cosine Similarity)

WidyaBase dilengkapi mesin kalkulasi vektor bawaan. Dengan membandingkan dua vektor embedding, WidyaBase dapat mengetahui seberapa mirip dua konsep atau produk: 

# Mengukur kemiripan antara Vektor A (Kopi Arabika) dan Vektor B (Kopi Robusta)

12.2 Proyek Latihan Akhir: Sistem Kasir Minimarket

📝 Soal Latihan Mandiri
Buatlah basis data baru bernama minimarket.wdb lalu selesaikan misi berikut:
  1. Buat tabel barang dengan kolom: kode INT KUNCI_UTAMA, nama TEKS, harga ANGKA, dan stok INT.
  2. Sisipkan 3 barang:
    • Kode 101: 'Beras Pandan Wangi 5kg', harga 75000, stok 20
    • Kode 102: 'Minyak Goreng 2L', harga 34000, stok 50
    • Kode 103: 'Gula Pasir 1kg', harga 17500, stok 15
  3. Tampilkan semua barang yang stoknya di bawah 30 dengan urutan harga termurah!
  4. Hitung total nilai aset seluruh persediaan barang (harga * stok) menggunakan kueri agregasi!

Kunci Jawaban Proyek Latihan:

-- 1. Membuat Tabel
BUAT_TABEL barang (
    kode INT KUNCI_UTAMA,
    nama TEKS,
    harga ANGKA,
    stok INT
);

-- 2. Menyisipkan Data
SISIP_KE barang (kode, nama, harga, stok) NILAI (101, 'Beras Pandan Wangi 5kg', 75000, 20);
SISIP_KE barang (kode, nama, harga, stok) NILAI (102, 'Minyak Goreng 2L', 34000, 50);
SISIP_KE barang (kode, nama, harga, stok) NILAI (103, 'Gula Pasir 1kg', 17500, 15);

-- 3. Kueri Stok < 30 Urut Termurah
PILIH nama, harga, stok 
DARI barang 
DIMANA stok < 30 
URUTKAN BERDASARKAN harga NAIK;

-- 4. Kueri Ringkasan Eksekutif
PILIH 
    HITUNG(*) SEBAGAI ragam_barang,
    JUMLAH(stok) SEBAGAI total_unit,
    JUMLAH(harga) SEBAGAI total_harga_katalog,
    RATA_RATA(harga) SEBAGAI harga_rata_rata 
DARI barang;
